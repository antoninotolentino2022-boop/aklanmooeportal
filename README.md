# Division of Aklan MOOE Liquidation Portal

Open the portal: **https://tinyurl.com/aklanmooe** (this site: https://antoninotolentino2022-boop.github.io/aklanmooeportal/)

This repository holds only the portal's web page (`index.html`). All records, photos and accounts stay in the Division's Google account (Google Sheets and Drive), reached through the portal's Google Apps Script web app. Hosting the page here lets it open in browsers that are signed in to several Google accounts.

`index.html` is a copy of `portal/Index.html` from the project; update both together.

Designed and developed by Antoniño F. Tolentino, Head Teacher I, Camanci Sur Elementary School.
